## What I Build

- **AI-assisted products**: prompt workflows, LLM-powered applications, agentic tooling, and productivity systems.
- **Local-first automation**: account cleanup, desktop utilities, CLI workflows, and safety-first operator tools.
- **Developer experience**: small tools that reduce repeated work, make systems easier to operate, and keep feedback loops short.

My default engineering bar: make the critical path usable, keep failure modes visible, document the operating boundary, and ship in small reversible steps.

## Repository Quality Checklist

I try to keep public projects useful to a first-time visitor:

- clear one-line problem statement
- quick start or demo path
- screenshots, GIFs, or live preview where they help
- explicit license and topics
- status label: usable, beta, experimental, or archived
- operational notes for risky workflows such as account cleanup, automation, or network tooling
